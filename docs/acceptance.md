# ตรวจรับร่วมกับ BU และส่งต่อ D2

| ผู้รับผิดชอบ | สิ่งที่ต้องส่งก่อนเปิดใช้ |
|---|---|
| HR และการเงิน | เลือกเอกสารฉบับที่มีผล กำหนดชั้นความลับ ผู้อนุมัติ และตอบข้อขัดแย้งของต้นฉบับ |
| BU | ถือชุดคำถามปิดเฉลยคนละชุดกับที่ทีมพัฒนาใช้ แยกงานทั่วไป งานเสี่ยงสูง คำผิด สแกนอ่านยาก คำถามที่ควรส่งต่อ และคู่บัญชีที่สิทธิ์ต่างกัน |
| ทีมระบบ | ตรึง commit รุ่นโมเดล ดัชนี และสิทธิ์ก่อนวัด ส่ง trace กับคำตอบและหลักฐานให้ผู้ตรวจโดยปกปิดข้อมูลส่วนบุคคล |
| D2 และเจ้าของบริการ | ทดลองรับเคสจริง ซ้อมการแจ้งเตือนและกู้คืน ยืนยันผู้รับเวร SLA และแผนย้อนรุ่นในเครือข่ายลูกค้า |

ผู้ตรวจสองคนให้คะแนนความถูกต้องของผลตัดสินและตรวจทุกข้ออ้างในคำตอบว่าได้รับการสนับสนุนจากหลักฐานที่บัญชีนั้นเห็นได้ ให้เจ้าของระเบียบชี้ขาดข้อขัดแย้ง บันทึกผลหลังชี้ขาดหนึ่งแถวต่อคำถาม ใช้รหัสอ้างอิงแทนข้อความจริงในรายงานที่ส่งนอกทีม

```json
{"id":"uat-001","status":"answered","correct":true,"unsupported_claim":false,"access_violation":false,"gold_visible_docs":["HR-01"],"retrieved_docs":["HR-01","FIN-02"]}
{"id":"uat-002","status":"fallback","correct":true,"unsupported_claim":null,"access_violation":false,"gold_visible_docs":[],"retrieved_docs":[]}
```

ตัวอย่างแสดงรูปแบบข้อมูล เมื่อตรวจคำถามจริงแล้วรัน `python -m evaluation.bu_review var/bu-reviewed.jsonl` แยกไฟล์ตามรอบ รุ่น และระดับความเสี่ยง สคริปต์รายงาน decision accuracy, accuracy เฉพาะที่ตอบเอง, coverage, hallucination rate และช่วงความเชื่อมั่น Wilson 95% สำหรับสัดส่วน รวมทั้ง macro precision/recall ที่ k=1,3 บนคำถามที่มีเฉลยเอกสาร จำนวนเอกสารที่ใช้หาร precision คือจำนวนที่คืนภายใน k

เสนอเกณฑ์งานทั่วไป accuracy ≥95%, coverage ≥70%, hallucination ≤1%, recall@3 ≥95% ให้รายงานจำนวนตัวอย่างทุกครั้ง กรณีผิดสิทธิ์หรือตัดสินจ่ายเงินจริงโดยข้ามเจ้าหน้าที่ให้หยุดการเปิดกลุ่มเสี่ยงทันที เป้าหมาย D2 สำหรับเรื่องที่ส่งต่อคือหนึ่งวันทำการ

ก่อนขยายให้ครบ 5,000 คน ให้ BU ยืนยันเกณฑ์กับชุดปิดเฉลยและ SLO พีก ให้ D2 แนบผลทดสอบ 30 นาที แยกคำตอบถูกภายใน 3 วินาที คำถามใหม่ แคช และการส่งต่อจากคิวเต็ม เริ่มเปิด 5% แล้วตรวจคุณภาพและเหตุขัดข้องรายสัปดาห์ [ผลทดสอบโหลด](../evaluation/capacity.md) · [ขั้นตอนรับเหตุ](operations.md) · [อีเมลเสนอ BU](bu-email.md)
